# Reminder

Локальное приложение для напоминаний с уведомлениями Windows. Сервера нет: данные хранятся только в браузере.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

## Возможности

- Повторы: однократно, каждые n часов, каждые n дней, по дням недели (пн–вс), каждые n месяцев, каждые n лет.
  31-е число в коротких месяцах и 29 февраля в невисокосные годы переносятся на последний день месяца.
- Заголовок, описание, цвет, иконка: встроенный выбор эмодзи, любой эмодзи через Win + . или свои картинки (PNG/JPG/GIF/SVG/WebP).
- Очередь с группировкой (сегодня / завтра / неделя / …), поиском, фильтрами по статусу, типу повтора и цвету, сортировкой.
- Уведомления Windows через Notification API и service worker (с кнопкой «Отложить»), плюс звук и уведомление внутри приложения.
- Пауза, дублирование, удаление с отменой, тестовое уведомление, экспорт и импорт резервной копии в JSON.

## Хранение

| Что | Где |
| --- | --- |
| Напоминания, настройки, фильтры | `localStorage` (`reminder.*`) |
| Свои картинки (data URL, до 128px) | IndexedDB `reminder-db` → `icons` |

## Ограничения

Браузер проверяет расписание, только пока открыта хотя бы одна вкладка приложения (её можно свернуть).
Если за время, когда вкладка была закрыта, пропущено несколько срабатываний, при следующем открытии придёт одно уведомление с пометкой «Пропущено».
При нескольких открытых вкладках уведомления отправляет только одна из них (Web Locks), поэтому дублей нет.
